JSON

Export als JSON → auf anderem Gerät (Handy, Tablet, PC) importieren. Alle Parameter und Sondertilgungen werden übertragen.

  • LocalStorage ist gerätespezifisch – für Geräteübergabe immer JSON-Export verwenden.
  • Beim Löschen des Browser-Caches gehen lokale Daten verloren.
  • Die JSON-Datei enthält keine personenbezogenen Daten außer den Kreditparametern.
